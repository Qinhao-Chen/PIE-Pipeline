# Earlier entry points

Use the maintained [Prune → Interpret → Evaluate workflow](../README.md) for new work.

`legacy/scripts/run_description.py` and `run_evaluation.py` forward to the maintained stage commands. The earlier `run_pruning.py` and `run_relp_pruning.py` remain as reference implementations with their original options.

Datasets, collected descriptions and experimental results are not included. Generate IOI inputs with `scripts/ioi.py` or supply local paired inputs following [the task format](../docs/TASKS.md). Keep generated data and outputs private.
